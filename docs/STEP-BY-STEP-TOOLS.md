# Step-by-Step — Versi 2: Dari Halaman Tools (untuk Operator)

Alur kerja kamu, dari cari calon pelanggan sampai restorannya jalan dan bayar langganan.

## 1. Cari lead — halaman /tools
1. Buka **/tools**
2. Isi kata kunci (mis. "warung makan", "cafe") + lokasi (mis. "Bandung")
3. Klik cari → daftar resto muncul dari Google Places
4. Pilih yang belum punya website / websitenya jelek → **Simpan sebagai lead**

## 2. Kelola lead — halaman /leads
5. Buka **/leads** → lihat daftar calon yang tersimpan
6. Hubungi via WhatsApp (template pesan tersedia) → tawarkan RestoLauncher
7. Catat status: dihubungi / tertarik / deal / batal

## 3. Deal → buatkan resto
8. Kalau deal, di /leads klik **"Buatkan dari Lead"**
9. Isi form: pilih **paket** (Basic/Plus/Premium), lengkapi data → resto terbuat, **PIN owner otomatis**
10. Pesanan paket tercatat di **/admin/package-orders**

## 4. Setup — dashboard resto
11. Buka dashboard resto → ikuti **checklist setup**:
    - Upload foto QRIS (dari WA pelanggan → auto-decode)
    - Tambah meja → **unduh QR tiap meja** (dari domain produksi, bukan localhost!)
    - Tambah menu + harga
    - Pilih tema (Basic: 3 pilihan · Plus: 6 · Premium: bebas 7)
12. Cek website: `restolauncher.com/r/slug-resto`

## 5. Serah terima via WhatsApp
13. Kirim ke owner: **link website, link kasir, PIN portal owner + link /owner, PDF panduan, file QR meja**
14. Ingatkan: tempel QR di tiap meja, bookmark halaman kasir di HP

## 6. Operasional & tagihan
15. Owner bisa kelola sendiri via portal: meja, menu, profil resto
16. Perubahan QRIS/tema/info → owner kirim via WA → kamu update di admin
17. Tagihan langganan bulanan: **manual** (catat & tagih via WA) — otomatisasi menyusul
