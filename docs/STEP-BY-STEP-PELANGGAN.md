# Step-by-Step — Versi 1: Dari Landing Page (untuk Calon Pelanggan)

Alur yang dialami pemilik resto, dari pertama buka website sampai restorannya jalan.

## 1. Kenalan — buka landing page
1. Buka **restolauncher.com**
2. Baca bagian **Fitur Lengkap** — tiap fitur ada contoh gambarnya (menu digital, QR meja, QRIS, kasir)
3. Baca **Cara Kerja** (4 langkah) biar kebayang alurnya
4. Lihat **Harga**: Basic Rp50rb/bln · Plus Rp99rb/bln · Premium Rp500rb sekali bayar + Rp49rb/bln

## 2. Pilih paket
5. Di tiap kartu paket ada label **"Cocok untuk"** — pilih yang sesuai skala usahamu
6. Klik **"Lihat Manfaat & Hitung-hitungan"** untuk rincian manfaat tiap fitur + simulasi balik modal
7. Klik **"Pilih Paket"**

## 3. Isi form pemesanan
8. Isi: nama resto, nama owner, nomor WhatsApp, catatan (mis. "sudah punya QRIS", "minta tema hijau")
9. Klik kirim → pesanan tercatat
10. (Opsional) Klik tombol WhatsApp untuk langsung chat dengan tim kami

## 4. Dihubungi tim RestoLauncher
11. Tim menghubungimu via WhatsApp (konfirmasi paket + tanya jawab)
12. Kirim data yang diminta via WA: **logo/foto, daftar menu + harga, foto QRIS**, alamat & jam buka

## 5. Setup oleh tim (kamu terima beres)
13. Website restomu dibuat: `restolauncher.com/r/nama-restomu`
14. Menu digital diisi, QR tiap meja dibuat, QRIS dipasang
15. Kamu terima via WA: **link website, link kasir, PIN portal owner, PDF panduan, file QR meja** (siap cetak)

## 6. Operasional harian
16. Tempel QR di tiap meja
17. Kasir: buka halaman kasir di HP → tiap pesanan masuk → dengar notifikasi bayar → ketuk **Tandai Lunas**
18. Butuh ubah menu/meja/tulisan? Buka **Portal Owner** (`restolauncher.com/owner`) pakai PIN — bisa edit sendiri
19. Butuh bantuan? Hubungi tim via WhatsApp kapan saja
